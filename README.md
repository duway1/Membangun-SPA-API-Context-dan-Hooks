# Expense Tracker App — Starter Project

Selamat datang di lanjutan membangun project Single Page Application bertemakan *Aplikasi Catatan Pribadi* 🎉🎉🎉

---

## Cara Menjalankan Proyek

**1. Install:** react-router-dom.
Di terminal VS Code, masuk ke folder project

```
npm install recat-router-dom
```

**2. Menjalankan Project:** Diterminal VS Code :
```
npm run dev
```
kemudian buka alamat yang diberikan Vite, biasanya : ``` http://localhost:5173/ ```
